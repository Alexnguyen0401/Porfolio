# AN.EXE — Portfolio demo

This is a visual, interactive HTML prototype for An Nguyễn's video-editor portfolio.

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in Chrome or Edge.
3. Click the four folder cards, use Previous / Next Folder, open About, and click video cards to see the preview modal.

## Demo notes
- The project cards and video modal are placeholders. They do not yet contain real videos.
- Replace the sample project list in the `folders` array near the bottom of `index.html` with your real project names and YouTube IDs when the design is approved.
- Contact details are intentionally placeholders in the About section. Add only contact information you want public.
- Google Fonts are loaded online; if unavailable, the page falls back to system fonts.
